# Vinyl CSS Animation

A **responsive web animation** project featuring a rotating vinyl disc with interactive button layouts. Built with **HTML and CSS only so far**, this project demonstrates modern front-end techniques for creating dynamic, visually appealing interfaces.

### ✨ Features
- **Smooth vinyl disc animation** with CSS `keyframes` and `transform`.
- **Responsive design** that adapts to screen size:
  - **Desktop (≥1300px)**: 3-column layout (left buttons, vinyl disc, right buttons).
  - **Mobile (<1300px)**: Vinyl disc on top, with buttons arranged below.
- **Customizable** button styles and animations.
- **Lightweight** and dependency-free.

### 🎯 Purpose
A fun experiment in **CSS animations, flexbox/grid layouts, and responsive design**, inspired by retro vinyl records. Ideal for learning or reusing in creative web projects.

### 🚀 How to Use
1. Clone or download the repository.
2. Open `index.html` in a browser.
3. Resize the window to see the responsive layout in action!

### 🛠️ Technologies
- **HTML5**
- **CSS3** (Flexbox, Grid, Animations)
- **Vanilla JavaScript** (optional, for future enhancements)
